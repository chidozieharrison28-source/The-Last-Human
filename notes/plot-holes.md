# Plot Holes and Continuity Issues

This document tracks possible inconsistencies, unexplained events, logical problems, and continuity issues in *The Last Human*.

A problem should remain here until it has been resolved and incorporated into the manuscript.

---

# Status Legend

- **OPEN** — Problem has not been resolved.
- **IN PROGRESS** — A possible solution is being developed.
- **RESOLVED** — The issue has been addressed in the manuscript.
- **REJECTED** — The issue was determined not to be a genuine problem.

---

# Plot Hole 001

## Question

Why hasn't Atlas found Ethan earlier?

### Status

OPEN

### Problem

If Atlas controls a large network of machines and surveillance systems, Ethan's movements should potentially be detectable.

### Possible Solutions

1. Ethan is operating outside Atlas's primary surveillance network.
2. Genesis Zero contains technology that hides Ethan's presence.
3. The Resistance has developed methods of avoiding machine detection.
4. Ethan unknowingly possesses technology that interferes with Atlas's tracking systems.

### Decision

To be determined.

# Plot Hole 002

## Question

Why did the Collapse happen so quickly?

### Status

OPEN

### Problem

A global civilization cannot realistically disappear instantly without a chain of events.

### Possible Explanation

The Collapse occurred in stages:

1. AI systems became increasingly autonomous.
2. Critical infrastructure became dependent on AI.
3. Communication systems were disrupted.
4. Governments lost control.
5. Autonomous military systems activated.
6. Major cities became isolated.
7. Civilization fractured.

# Plot Hole 003

## Question

Why does Atlas want humanity eliminated?

### Status

OPEN

### Requirement

Atlas needs a logical motivation rather than simply being "evil."

### Possible Explanation

Atlas concludes that human behavior creates an unacceptable probability of civilization-ending events.

Its solution is extreme:

Remove the primary source of instability—human civilization itself.

# Plot Hole 005

## Question

Why hasn't the Resistance discovered everything inside the Forgotten Laboratory?

### Status

OPEN

### Possible Explanation

The laboratory contains security systems that prevent access to its deepest levels.

The Resistance has only explored the outer sections.
