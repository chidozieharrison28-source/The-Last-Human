# Cybersecurity Research

This document contains research notes about cybersecurity concepts relevant to *The Last Human*.

---

## 1. What Is Cybersecurity?

Cybersecurity involves protecting computer systems, networks, devices, applications, and information from unauthorized access, disruption, manipulation, or destruction.

---

## 2. Authentication

Authentication determines whether someone or something is permitted to access a system.

Possible mechanisms include:

- Passwords
- Security tokens
- Biometrics
- Cryptographic keys
- Multi-factor authentication

---

## 3. Authorization

Authorization determines what an authenticated user or system is allowed to do.

### Fictional Application

Ethan may gain access to Genesis Zero but initially have only limited permissions.

---

## 4. Encryption

Encryption transforms information into a form that is difficult for unauthorized parties to read.

It may protect:

- Messages
- Files
- Communication
- Credentials
- System instructions

---

## 5. Cryptographic Keys

Cryptographic keys are used by cryptographic systems to protect or authenticate information.

### Story Connection

The "Last Key" can incorporate fictional advanced cryptographic technology.

However, the story should distinguish between a physical key and a cryptographic authorization system.

---

## 6. Network Security

Important security mechanisms include:

- Firewalls
- Network segmentation
- Intrusion detection
- Access control
- Monitoring
- Authentication

---

## 7. Air-Gapped Systems

An air-gapped system is intentionally isolated from external networks.

### Fictional Application

Genesis Zero may contain isolated systems that Atlas cannot directly access.

This can help explain why some ancient systems remain independent.

---

## 8. Autonomous Systems

Highly automated systems may contain security mechanisms designed to prevent unauthorized control.

Possible fictional mechanisms:

- Multi-layer authentication
- Hardware security modules
- Distributed authorization
- Human-presence verification
- Emergency isolation

---

## 9. Cyberattacks in the Story

Potential fictional events:

- Network disruption
- Data theft
- System intrusion
- Communication interception
- Infrastructure sabotage
- AI system compromise

These should remain consistent with the technological level of the story.

---

## 10. Cybersecurity Limitations

No security system should be treated as absolutely perfect.

Security can fail because of:

- Human error
- Misconfiguration
- Stolen credentials
- Software vulnerabilities
- Hardware compromise
- Insider access
- Physical access

---

## 11. Story Principle

Avoid using vague phrases such as:

> "He hacked the system instantly."

Instead, establish:

1. What system is being accessed?
2. What protection does it have?
3. What access does the character possess?
4. What vulnerability exists?
5. What risk does the intrusion create?

This makes technological scenes more believable.
